КАК ЗАПУСТИТЬ

1. Открой index.html двойным кликом.
2. Секретный код по умолчанию: 2408.
3. Все основные личные тексты находятся в самом начале script.js, внутри CONFIG.
4. Чтобы добавить музыку, положи mp3-файл сюда:
   assets/music.mp3
5. Фото/скрины пока не подключены специально — это следующий шаг, когда решим, как именно ты хочешь их показывать.

ФАЙЛЫ
- index.html — структура сайта
- style.css — внешний вид
- script.js — содержимое и интерактив
- assets/ — музыка, фото, видео и т. п.
